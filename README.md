# CODEXI Icon Generator

ゲーム **CODEXI** で使用される属性・技アイコン画像をブラウザ上で生成・ダウンロードできるWebツールです。

🔗 **https://omezi42.github.io/codexi-icon/**

## 機能

- 🎨 **自由生成** — 左・右の文字と背景色を指定してオリジナルアイコンを即時生成
- 🗂 **プリセット** — 既存19種のアイコン（弱攻・防御・スロー等）をワンクリック選択
- ⬇ **PNG ダウンロード** — 90×90 / 180×180 / 270×270 で書き出し
- ✅ **98%精度テスト** — 生成画像と元画像をピクセル単位で比較（全19種）

## アルゴリズム

元画像から抽出したサブピクセルマスク（RGB各チャンネル独立）を使用し、背景色とブレンドして完全再現します。

```
output[c] = round( bg[c] + (t_c/255) × (255 - bg[c]) )
```

全19種で **99.78%〜100.00%** のピクセル完全一致率を達成（合格ライン 98%）。
